# サブ機能: 薬と食材の相互作用チェック

関連タスク: Issue #14（GET/POST /api/medicines 薬管理API）/ #15（レシピ提案時の薬・食材相互作用チェック機能）

## 概要
服用している薬を登録しておくと、レシピ提案時に薬との相性が悪い食材を自動で警告する機能。

## ユースケース
- ワルファリン服用中 → 納豆・ブロッコリーなどビタミンKの多い食材に注意を表示
- 降圧剤服用中 → グレープフルーツとの相互作用を警告
- MAO阻害薬服用中 → チーズ・赤ワインなどチラミンの多い食品を警告

## 仕組み
1. ユーザーが薬管理画面で服用中の薬を登録する（薬名をテキスト入力）
2. レシピ提案リクエスト時に、登録済みの薬情報もプロンプトに含める
3. AIがレシピ提案と同時に、食材と薬の相互作用に関する注意事項を返す

## 薬管理API（Issue #14）
- `POST /api/medicines` : 薬名を登録
- `GET /api/medicines` : 登録済み薬一覧を取得
- `DELETE /api/medicines/{id}` : 薬を削除
- `medicines` テーブルのモデル・マイグレーションも合わせて作成する

## 相互作用チェック（Issue #15）
- `POST /api/suggest-recipes` 実行時に登録済み薬情報を取得してプロンプトに追加する
- AIが相互作用ありと判断した場合、レスポンスに `warnings` フィールドを付与する

レスポンス例:
```json
"warnings": [
  {"ingredient": "納豆", "reason": "ワルファリンの効果を弱める可能性があります"}
]
```

### プロンプトへの追加
```
【服用中の薬】ワルファリン

上記の薬と相性の悪い食材がレシピに含まれる場合は、以下の形式で警告を追加してください：
- warningIngredient: 注意が必要な食材名
- warningReason: 注意が必要な理由（1文）
```

## 注意事項
- 「AIによる参考情報であり、医療上の判断は必ず医師・薬剤師にご相談ください」という免責事項を必ず表示する
- この機能はあくまでサブ機能として位置づけ、メインのレシピ提案機能の完成を優先する
