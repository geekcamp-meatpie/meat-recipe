# 提案モード・お好み設定・プロンプト設計

関連タスク: Issue #3（ai clientの設定と呼びだし）/ #12（お好み設定フィルタリングロジック）

> 以下のプロンプト例は、DB検索結果が不足したときのAIアレンジ補完（Issue #13）や、画像認識・薬チェックなどAIを直接呼び出す処理に適用する。DBから取得したレシピそのものにはこのプロンプトは通さない。取得方針全体は [recipe-retrieval-strategy.md](recipe-retrieval-strategy.md) を参照。

## 提案モード

ユーザーは2つのモードから選択できる。

### モード1: 手持ち食材のみモード
入力した食材だけで作れる料理を提案する。追加の買い物なしで作れるレシピのみが表示される。

### モード2: おまかせモード
入力した食材を含めつつ、手元にない食材も使ったレシピを提案する。「この食材があればこんな料理も作れる」という発見を提供する。

### プロンプトへの反映

**モード1の場合**
```
【制約】提案するレシピは、以下の食材と一般的な調味料（塩、こしょう、砂糖、醤油、みりん、酒、油）のみで作れるものに限定してください。追加で購入が必要な食材は使わないでください。
```

**モード2の場合**
```
【制約】以下の食材を必ず使用してください。それ以外に必要な食材がある場合は「追加で必要な食材」として明記してください。
```

## お好み設定機能

### 設定カテゴリ

#### 味の方向性（単一選択）
しょうゆ系 / 味噌系 / 塩系 / ソース系 / ケチャップ系 / ピリ辛 / 酸味系 / クリーム系 / おまかせ

#### 調理法（単一選択）
焼く / 炒める / 煮る / 蒸す / 揚げる / 生・和える / おまかせ

#### 料理のジャンル（単一選択）
和食 / 洋食 / 中華 / 韓国 / エスニック / おまかせ

#### ボリューム感（単一選択）
がっつり / 普通 / 軽め

### 設計ポイント
- 全カテゴリに「おまかせ」を用意し、何も選ばずスキップ可能にする
- 「おまかせ」が選ばれた項目はプロンプトから省略（AIが自由に判断）／DBフィルタからも除外する（Issue #12）
- こだわりたい人だけ設定する設計で間口を広く保つ

### プロンプト例

```
あなたは料理提案AIです。以下の条件でレシピを3つ提案してください。

【食材】鶏もも肉(300g)、玉ねぎ(1個)、じゃがいも(2個)
【モード】手持ち食材のみ
【味の方向性】ピリ辛
【調理法】炒める
【ジャンル】韓国
【ボリューム】がっつり

各レシピについて以下のJSON形式で返してください：
- recipeName: 料理名
- cookingTime: 調理時間（分）
- difficulty: 難易度（簡単/普通/本格的）
- ingredients: 材料リスト（手持ち食材＋追加で必要な調味料）
- steps: 手順（配列）
- point: 美味しく作るコツ（1文）
```
