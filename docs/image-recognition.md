# 画像認識の精度対策

関連タスク: Issue #10（POST /api/recognize-ingredients 画像認識エンドポイント）

## 方針
「認識精度を100%に近づける」よりも「70%の精度でも快適に使えるUX設計」に注力する。

## 3段構えの対策

### 対策1: プロンプト側のチューニング
- 構造化されたプロンプトでJSON形式 + confidenceスコア付きで返させる
- 確信度が低い食材のみユーザーに確認を求める分岐を作る

### 対策2: 撮影条件をUXで制御
- カメラ起動時に撮影ガイドを表示（「明るい場所で、食材をバラして撮影してください」等）
- 1食材ずつ撮影モードを用意
- 枠やオーバーレイで撮影範囲をガイド

### 対策3: UXで精度の低さを吸収（最重要）
- AI認識結果をタグ形式で表示し、タップで削除・編集可能にする
- 「これも入ってた」で手動追加できるテキスト入力欄を常に表示
- よく使う食材をサジェスト候補として出す（卵、玉ねぎ、にんじん等）

## エンドポイント仕様（Issue #10）

- リクエスト: 画像バイナリ（multipart/form-data）
- Gemini マルチモーダルAPIに画像を送り、食材名・量・confidenceスコアをJSON形式で取得する
- レスポンス例:
```json
[
  {"name": "鶏もも肉", "amount": "300g", "confidence": 0.95},
  {"name": "玉ねぎ", "amount": "1個", "confidence": 0.80}
]
```
- Pydanticでリクエスト・レスポンスのスキーマを定義する
